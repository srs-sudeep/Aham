# Backend overview

FastAPI services on a shared **platform-kit**. Product code = **modules** with fixed layers; infrastructure stays in the kit.

## Stack

| Layer | Choice |
|---|---|
| Language | Python ≥ 3.12 |
| HTTP | FastAPI + Uvicorn |
| ORM | SQLAlchemy 2 async + asyncpg + Alembic |
| Settings | Pydantic Settings (`ServiceSettings`) |
| Logging | structlog |
| Auth | JWT (HS256 or JWKS); SaaS: TokenIssuer + Redis refresh |
| Messaging | Optional Kafka + FastStream + transactional outbox |
| Tooling | uv, Ruff, Pyright, pytest, `dx` (argparse CLI) |
| Observability | OTel extras + Jaeger Compose profile |
| Deploy | Docker + Compose (no K8s in template) |

## Entrypoint

```python
app = create_app(
    settings=settings,
    package="core_api",
    role_permissions=ROLE_PERMISSIONS,
)
```

- Discovers `modules/*/router.py` (+ `extra_routers`)
- Mounts under **`/api/v1`**
- Health (unprefixed): `/health/live`, `/health/ready`
- Host port in examples: **8001 → 8000**
