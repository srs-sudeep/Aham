# Backend examples

## `mono-monolith`

```bash
cp .env.example services/core-api/.env
docker compose up -d postgres redis
uv run dx run core-api
```

Modules: identity, billing, items. Redis required.

## `mono-micro-kafka-nx` / `mono-micro-moon`

Single `core-api` + items. Kafka variant: contracts + `localhost:29092`.

## `poly-kit`

Publishes kit + contracts; `v*` release; SaaS CLI templates.

## `poly-service-kafka`

Flat `src/core_api/`; kit path-pinned to `../poly-kit`; root `.env`.
