# Platform kit

Path (dev): `backend/mono-monolith/packages/platform-kit/src/platform_kit/`

## Modules

| Module | Role |
|---|---|
| `app` | `create_app`, router discovery, `load_models` |
| `rbac` | `SecureRouter`, `Permission`, `Action`, `PUBLIC` |
| `permission_resolver` | Redis → DB → code |
| `errors` | Typed errors + envelope |
| `logging` / `middleware` / `context` | Observability & request context |
| `db` | `Base`, mixins, `Database`, `BaseRepository` |
| `health` | live/ready |
| `security` | JWT |
| `http` | `ServiceClient` |
| `messaging` | Event, outbox, subscribers |
| `telemetry` | OTel |
| `redis` / `cache` / `rate_limit` | Redis helpers |
| `tenancy` | Tenant deps, RLS |
| `entitlements` | `require_feature` / `require_quota` |
| `audit` | Audit helpers |
| `api_keys` / `mfa` / `oidc` | Phase 2 |
| `stripe_billing` / `providers` | Payments + ports |
| `testing` | Test utils (`memory://` Redis) |
| `cli` | `dx` |

## Public exports (`__init__`)

`create_app`, `ServiceSettings`, `get_logger`, `PUBLIC`, `Action`, `Permission`, `SecureRouter`, error types listed in [Architecture](./architecture.mdx).

## Extras

```text
platform-kit[otel]

```

Script entry: `dx = platform_kit.cli.main:main`.

## Kit sync rule

Develop in mono-monolith kit → rsync to template + other examples (exclude `*.jinja`, `project.json`, `moon.yml`). See [Meta-repo](../getting-started/meta-repo.mdx).
