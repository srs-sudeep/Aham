# Platform kit

`platform-kit` is the shared FastAPI baseline. In monorepos it lives at `packages/platform-kit/`. Polyrepo services pin it as a dependency.

## Surface area (top-level modules)

| Area | Role |
|---|---|
| `app` | `create_app`, router discovery, `extra_routers` |
| `rbac` | `SecureRouter`, `Permission`, role maps |
| `permission_resolver` | Redis → DB → code permission resolution |
| `errors` | Typed `AppError` hierarchy + envelope |
| `logging` | structlog helpers |
| `middleware` | Request ID, timing, etc. |
| `db` | Async session, `BaseRepository` |
| `health` | `/health/live`, `/health/ready` |
| `security` | JWT verify / issue helpers |
| `http` | `ServiceClient` for service-to-service calls |
| `messaging` | FastStream + outbox (Kafka extra) |
| `telemetry` | OpenTelemetry wiring |
| `redis` / `cache` | Redis client + cache helpers |
| `context` | Request/tenant context |
| `tenancy` | Tenant mixins, RLS helpers |
| `entitlements` | Features / quotas |
| `audit` | Enterprise-shaped audit helpers |
| `rate_limit` | Redis-backed limits |
| `api_keys` | API key helpers |
| `mfa` / `oidc` | MFA + OIDC helpers |
| `stripe_billing` | Stripe billing adapter |
| `providers` | Phase-2 ports: SSO, SCIM, Stripe, email stubs |
| `testing` | Test utilities |
| `cli` | The `dx` tool and generators |

## Extras

```text
platform-kit[otel]
platform-kit[otel,saas]
platform-kit[otel,kafka]
platform-kit[stripe]
platform-kit[redis]
platform-kit[testing]
```

## Protection

Do **not** edit kit paths in product repos unless you are a lead and export:

```bash
export DX_ALLOW_BASELINE=1
```

AI hooks and `dx check` block casual baseline edits. Prefer contributing kit changes upstream (poly-kit / template) and bumping consumers.
