# Testing & CI

## Local tests

| Kind | Location |
|---|---|
| API | `tests/api/` — real auth: 200/401/403/404/422 |
| Unit | `tests/unit/` — fake repos |
| Architecture | `tests/test_architecture.py` |
| Kit | `packages/platform-kit/tests/` |
| Fuzz | Schemathesis vs `/openapi.json` in CI |

Coverage: `fail_under = 80`.

```bash
uv run dx test --service core-api --cov
```

## Example CI (mono-monolith)

Micro/poly-service add **`contract`** (oasdiff). Poly-kit: `kit-tests` + `release` on `v*`.
