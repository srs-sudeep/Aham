# Modules

```bash
uv run dx new-module <service> <plural_snake_name>
# uv run dx new-module core-api purchase_orders
```

## Layout

```text
modules/<module>/
  router.py schemas.py service.py repository.py models.py dependencies.py
  errors.py events.py constants.py phase2.py scim_router.py   # optional
```

## Checklist

**Endpoint:** `async def`, `permission=`, `summary=`, return schema, thin body.

**Service:** `<Entity>Service`, no FastAPI, kit errors, one `repo.commit()` per write.

**Tests:** `tests/api/test_<module>.py` + `tests/unit/test_<module>_service.py`.

:::note Example coverage
mono-monolith ships API/unit tests for **items**; identity/billing rely heavily on kit `test_saas_spine` until you add service tests.
:::

## DoD

```bash
uv run dx fmt && uv run dx lint --service <s> && uv run dx test --service <s>
```
