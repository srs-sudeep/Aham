# SaaS spine

Enabled when `platform_profile=saas` (default).

## Capabilities

| Area | Details |
|---|---|
| Local IdP | register/login; access JWT + hashed refresh in Redis |
| Cookies | httpOnly refresh under `/api/v1/auth` (`TOKEN_DELIVERY=both`) |
| Tenancy | memberships, select/switch tenant, `tid` claim |
| Entitlements | plans/features/quotas |
| Audit | `/auth/audit` |
| Rate limits | login/register |
| Billing | ManualProvider default; Stripe optional |

## Scaffold

```bash
uv run dx new-saas core-api                 # modules in-service
uv run dx new-service identity --with-saas  # micro layout
uv run dx new-service billing --with-saas
```

Compose: `postgres` + **`redis`**.
