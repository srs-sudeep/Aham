# dx CLI

```bash
uv run dx <command>
```

Source: `platform_kit.cli.main` (argparse).

## Commands

| Command | Flags / args |
|---|---|
| `check` | `[paths…]`, `--service`, `--format text\|github` |
| `watch` | re-check on save |
| `lint` | `--service`, `--fix` |
| `fmt` | |
| `test` | `--service`, `--cov`, then pytest args |
| `services` | `--json` |
| `run` | `<service>`, `--port`, `--no-reload` |
| `up` / `down` / `logs` | `[only…]`, `--observability`, `--volumes` (down) |
| `db` | `upgrade\|downgrade\|revision` `<service>` `-m` `--revision` |
| `affected` | `--base` (default `origin/main`), `--json` |
| `openapi` | `<service>`, `-o` |
| `permissions` | `<service>` |
| `token` | `<service>`, `--perm` (repeat), `--all`, `--sub`, `--ttl` |
| `new-service` | `<name>`, `--with-example`, `--with-saas` |
| `new-saas` | `<service>`, `--modules identity billing` |
| `new-module` | `<service> <name>`, `--entity` |
| `rules` | list codes |
| `hook` | `claude-pre` \| `claude-post` |

## Generators reminder

Always use generators for modules/services — hand-created folders fail `STR*` checks.
