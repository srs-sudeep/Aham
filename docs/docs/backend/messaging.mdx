# Messaging (Kafka)

`messaging=kafka` adds broker + FastStream + outbox + `packages/contracts`.

## Compose

- Image: `apache/kafka:3.9.0` (KRaft)
- Host bootstrap: **`localhost:29092`**
- Env: `KAFKA_ENABLED=true`, `KAFKA_BOOTSTRAP_SERVERS=localhost:29092`

## Kit APIs

| API | Role |
|---|---|
| `Event` | Base event (`topic`, `version`, `event_id`, `occurred_at`) |
| `OutboxMessage` | DB row |
| `outbox.add(session, event)` | Same transaction as domain write |
| `@subscriber(Event, group=...)` | Consumer in `events.py` |
| `Messaging.start/stop` | Lifecycle |

## Contracts example

```text
packages/contracts/src/contracts/events/example.py
```

`ExampleItemCreated` → topic `example.item.created.v1`, fields `item_id`, `name`.

:::note
Shipped Kafka examples include contracts + infra. The `items` module may not yet publish — use contracts as the pattern when wiring events.
:::

## Outbox settings

`OUTBOX_POLL_SECONDS` (default `1.0`), `OUTBOX_MAX_ATTEMPTS` (default `10`).
