# UI kit (`@aham/ui-kit`)

Protected baseline. Edit only with `DX_ALLOW_BASELINE=1`.

## Layers

```text
src/primitives/          # layer 0 — kit-internal shadcn/radix wrappers
src/components/          # layer 1 — public components + icons
src/{layout,data,form,feedback,patterns}/   # layer 2
src/{shell,preferences,api,i18n,format,tenancy,auth,testing}/
```

## Package exports

| Export | Contents |
|---|---|
| `@aham/ui-kit` | auth, preferences, shell, modules helpers, tenancy, format, … |
| `@aham/ui-kit/components` | ~20 primitives + typography + icons |
| `@aham/ui-kit/data` | `DataTable`, `FilterBar`, `Pagination` |
| `@aham/ui-kit/form` | `Form`, `FormField`, `FormSection`, `FormActions`, `useZodForm`, `mapServerErrors` |
| `@aham/ui-kit/layout` | `Page`, `PageHeader`, `Section`, `Breadcrumbs` |
| `@aham/ui-kit/feedback` | `QueryState`, `EmptyState`, `ErrorState`, `ConfirmDialog` |
| `@aham/ui-kit/patterns` | `ListPage`, `DetailPage`, `FormPage` |
| `@aham/ui-kit/testing` | `TestProviders`, `createTestQueryClient` |
| `@aham/ui-kit/tokens.css` | CSS tokens |

Primitives (~20): avatar, badge, button, card, checkbox, dialog, dropdown-menu, input, label, scroll-area, select, separator, sheet, skeleton, sonner, switch, table, tabs, textarea, tooltip.

## AppShell

Props: `brand`, `navGroups` (preferred), `children`, `topbarExtra`, `onNavigate`, `currentPath`. Filters nav by `can()`; collapse via preferences; mobile Sheet.

## Modules helpers

`defineModule`, `defineFeature`, `buildNavGroups`, `collectLocales`.

## Tenancy helpers

`TenantProvider`, `useTenant`, `get/setStoredTenantId`, `TENANT_STORAGE_KEY` (`aham.tenant.id`).

## Template parity

`template/frontend` ui-kit and `frontend/web-spa` packages are kept in sync by `check-examples.sh` (Jinja only parameterizes brand/env).
