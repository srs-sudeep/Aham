# Frontend dx check

```bash
pnpm dx check
pnpm dx check --format github
pnpm dx rules
```

Hooks: `pre` blocks ui-kit edits without baseline flag; `post` runs **full** checks.

## Generators

| Command | Purpose |
|---|---|
| `pnpm new-module <name>` | Scaffold module + register |
| `pnpm new-feature <module>/<name>` | Scaffold feature + register in `module.ts` |
| `pnpm gen-api [openapi-url]` | Write `apps/web/src/lib/api-types.ts` |

## FE-* rule codes

| Code | Meaning |
|---|---|
| `FE-STR001` | Module missing `module.ts` |
| `FE-STR002` | Module missing `public.ts` |
| `FE-STR003` | Feature missing folders (`api\|hooks\|views/pages\|views/components\|routes\|model\|locales`) |
| `FE-STR004` | Feature missing `index.ts` |
| `FE-STR005` | Unexpected nesting |
| `FE-STR010` | Path depth exceeded |
| `FE-STR011` | Module features array must list manifests |
| `FE-STR012` | Cross-module internal import |
| `FE-LAY001`–`005` | Layering (views↛api, hooks↛JSX, api↛React, model pure, components↛api) |
| `FE-IMPORT001`–`003` | Deep imports / banned packages / axios |
| `FE-UI001` | Arbitrary Tailwind visual values |
| `FE-RBAC001` | Route must declare permission |
| `FE-DATA001` | useQuery/useMutation only in hooks |
| `FE-MEM001` | Effect listeners need cleanup |
| `FE-RESP001` | Fixed large widths in views |
| `FE-I18N001`–`002` | Hardcoded strings / missing sibling keys |
| `FE-THEME001` | documentElement theme/locale only in kit |
| `FE-CORE001` | Protected path without `DX_ALLOW_BASELINE=1` |
