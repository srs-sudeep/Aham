# Frontend dx check

```bash
pnpm dx check
pnpm dx rules
```

`dx check` runs the **full** frontend rule set on the whole repo (commit + CI). Claude hooks:

- `hook pre` — blocks ui-kit edits unless `DX_ALLOW_BASELINE=1`
- `hook post` — runs **full** `runChecks` (not edited-file-only)

## Rule families

Codes are prefixed **`FE-`**. Run `pnpm dx rules` for the full list. Families include:

| Family | Focus |
|---|---|
| `FE-STR*` | Structure / required folders |
| `FE-LAY*` | Layering (api/hooks/views separation) |
| `FE-UI*` | Import only from ui-kit; no raw internals |
| `FE-IMPORT*` | Import hygiene |
| `FE-RBAC*` | Permissions on non-core routes |
| `FE-DATA*` | Query/data access patterns |
| `FE-MEM*` | Memory / effect hygiene |
| `FE-I18N*` | No hardcoded user copy |
| `FE-THEME*` | No rogue colors/themes |
| `FE-RESP*` | Responsive / layout expectations |
| `FE-CORE*` | Core route / shell invariants |

`FE-STR001` currently requires feature dirs `api` / `hooks` / `views` / `routes`. **`locales/`** is created by `dx new-feature` and required by convention/AGENTS, but is not yet in that required-dirs check.

## Definition of done

```bash
pnpm dx check
pnpm test
pnpm build
```
