# Theming & i18n

## Preferences (`PreferencesProvider`)

| Field | Values |
|---|---|
| `themeMode` | light / dark / system |
| `colorPreset` | default / ocean / forest / contrast |
| `locale` | en / ja |
| `density` | comfortable / compact |
| `sidebarCollapsed` | boolean (API exists; limited UI exposure) |
| `timezone` / `currency` / `dateFormat` | regional (settings UI) |

Setters live on the kit only — `FE-THEME001` forbids `documentElement` theme/locale writes from apps.

Persistence: **`aham.preferences.v1`** in localStorage (no server sync yet).

`/settings` tabs: Appearance / Language / Regional.

## i18n

- Bootstrap: `lib/i18n.ts` + `collectLocales(registeredModules, coreLocales)`
- Seed default: `VITE_DEFAULT_LOCALE`
- Namespaces: `common`, `shell`, `login`, `home`, `settings`, `catalog`, `items.*`, `categories.*`, …
- Always `t()`; nav uses `labelKey`
- `FE-I18N001` / `FE-I18N002` — no hardcoded copy; sibling locale keys must match

## Format helpers

`formatNumber`, `formatMoney`, `formatDate`, `formatDateTime` from `@aham/ui-kit`.
