# Connecting to the API

## Env

```bash
# frontend/web-spa/.env
VITE_API_BASE_URL=http://localhost:8001/api/v1
VITE_DEFAULT_LOCALE=en
VITE_AUTH_MODE=saas
# VITE_USE_MOCKS=1
```

**Important:** the base URL **includes** `/api/v1`. Feature clients call `/items`, `/auth/login`, etc. relative to that base — matching backend mounts.

No Vite proxy — browser calls the API origin directly (configure `CORS_ORIGINS` on the API).

## Client

`apps/web/src/lib/api.ts`:

- Builds `apiClient` from `VITE_API_BASE_URL`
- Attaches `Authorization: Bearer` from `aham.auth.token`
- `refreshSession` on 401 (SaaS)
- Exposes `AUTH_MODE`

Hooks obtain the client via `useApi()` from the kit `ApiProvider`.

## Pairing

| Side | URL |
|---|---|
| mono-monolith | `http://localhost:8001` |
| SPA | `http://localhost:5173` |
| OpenAPI → types | `pnpm gen-api http://localhost:8001/openapi.json` → `apps/web/src/lib/api-types.ts` |
