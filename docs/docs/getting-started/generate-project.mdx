# Generate a project

```bash
cd /path/to/Aham
uvx copier copy --trust ./template my-new-project
```

`--trust` is required so post-copy tasks can run. Minimum Copier: **9.4.0**.

## Prompt flow

1. **stack** — `backend` | `frontend`
2. **project_name** / **project_slug**
3. Backend: `repo_layout`, `architecture`, `messaging`, `platform_profile`, `repo_manager`, …
4. Frontend: `api_base_url` (include `/api/v1`), **`auth_mode`** (`saas` | `dev`), `default_locale`
5. **ai_tools** — Claude and/or Cursor

Full matrix: [Copier options](../template/copier-options.mdx).

## Backend post-copy tasks

| Step | Command | When |
|---|---|---|
| 1 | `uv sync --all-packages --no-install-project` | copy |
| 2 | `uv run dx new-service {{ first_service }} --with-example` | not kit |
| 3 | `uv run dx new-saas {{ first_service }}` | saas + not microservices |
| 4 | `dx new-service identity --with-saas && billing --with-saas` | monorepo + micro + saas |
| 5 | `uv sync --all-packages` | copy **and** update |
| 6 | ruff format/check (`\|\| true`) | copy |
| 7 | `git init -b main` + pre-commit | copy |

## Frontend post-copy tasks

1. `pnpm install || (npm install -g pnpm && pnpm install)`
2. `pnpm dx check` (best-effort)
3. `git init` + stage

## Skip tasks

```bash
uvx copier copy --trust --skip-tasks --defaults \
  --data stack=frontend --data project_slug=web-spa \
  --data auth_mode=saas \
  ./template /tmp/out
```

Examples in this repo are maintained with `--skip-tasks` + manual install; see [Example drift](../template/example-drift.mdx).

## Update

```bash
cd my-project
uvx copier update --trust
```
